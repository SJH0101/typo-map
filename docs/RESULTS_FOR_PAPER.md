# 논문에 쓸 결과 — 2026-09-12

지금까지 나온 결과 가운데 논문에 들어갈 수 있는 것만 모았다. 항목마다 **논문 수치로 쓸 수 있음** / **탐색용** 을 붙이고 탐색용이면 그 까닭을 적는다. 기준은 `CLAUDE.md`: 사전등록을 실행 전에 단독 커밋했는가, 참조가 정답인가(합성) 아니면 사람 한 명의 참조인가, 결과를 보고 파라미터를 바꾸지 않았는가. 사람이 만든 자료는 «정확도» 가 아니라 «참조와의 일치도» 로 적고 라벨러 수를 같이 적는다.

수치의 출처 파일과 커밋을 항목마다 적었다. 인용할 때 `docs/legacy_numbers.md` 를 먼저 본다.

## 4. 검출기 비교와 오라클 상한 — **탐색용** (방법 섹션에 한 줄)

- 한 줄: «검출기는 Surya(surya-ocr 0.22.1)로 정했다. 라벨러 1인의 참조 상자 26장 · 130개와의 F1 은 EasyOCR 0.292 · Surya 0.576 · VLM 0.677 이었고 Surya−VLM 차이의 부트스트랩 구간이 0 을 포함했으며([−0.231, 0.026]) VLM 은 실행 간 일치가 0.735 로 결정론적이지 않아 Surya 를 택했다.
