- **만든 이의 근거.** 파일 안의 필드(`라벨한사람`·`찍은사람`·`labeler`)나 문서가 직접 적은 말만 썼다. 커밋 작성자는 근거로 쓰지 않았다. 커밋은 모두 `Junhyeok Song` 이름으로 올라가지만 절반 넘게 Claude 와 함께 썼기 때문이다. 기록이 없으면 **기록 없음**으로 적었다.

- **라벨러 수.** 둘째 라벨러가 있는 자료는 **하나도 없다.** 그래서 아래 자료는 모두 정답이 아니라 **참조**다.
