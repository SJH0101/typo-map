# Brockmann *Grid Systems* — 규칙 추출 및 목적 매핑 v1

원전: Müller-Brockmann, *Grid Systems in Graphic Design* (OCR 전문 기준)
구조: **0층(목적) → 1층(상수) → 2층(조건부 관계 규칙) → 3층(판단 원리)** + 목적 충돌 쌍

## 0층 — 목적 계층 (규칙들의 "왜"가 수렴하는 지점)

책 전체에서 브로크만이 규칙을 정당화할 때 반복적으로 소환하는 상위 목적. 모든 하위 규칙은 이 중 하나 이상을 섬긴다.

| ID | 목적 | 원전 근거 |
|----|------|-----------|
| P1 | **독서 노동 최소화** (눈의 피로, 읽기 속도) | "Every difficulty in reading means a loss of quality in communication and memorability" — 단폭·행간·여백 장 전반 |
| P2 | **이해와 기억** | "정보가 더 빨리 읽힐 뿐 아니라 더 잘 이해되고 기억된다. 이것은 과학적으로 입증된 사실" — 목적 장 |
| P3 | **신뢰 형성** | "질서는 정보의 신뢰도를 높이고 확신을 유도한다(Orderliness lends credibility... induces confidence)" — 목적 장 |
| P4 | **경제성·합리화** | "적은 시간과 비용으로 문제 해결(economic reasons)" — 목적 장, 판형 장 |
| P5 | **통일성·고요함** | "크기 차이가 적을수록 인상이 고요하다" — 그리드 장의 유일한 명시적 'The rule' |
| P6 | **긴장·리듬·대비** | "고유한 리듬을 지닌 압축적 배열", "높은 긴장도로 구조화된 시각 자료", 여백에서 "최대의 긴장" — 목적 장, 여백 장 |
| P7 | **사회적 책임** | "객관적이고 공공선에 헌신하는 디자인은 민주적 행동의 기초" — 철학 장 |

⚠️ **P5 ↔ P6은 구조적 긴장 관계.** 고요함과 긴장을 동시에 요구함. 브로크만의 "판단"은 상당 부분 이 둘의 중재였음 (아래 충돌 쌍 참조).

즉시 코딩 가능한 값들. 각 상수에 섬기는 목적 태깅.

| # | 규칙 | 값 | 목적 | 비고 |
|---|------|-----|------|------|

| C5 | 재단 공차 | **1–3mm, 최악 5mm** | P4 | 여백 최소값의 기술적 하한을 결정 |
| C6 | 굵기 3단계의 회색값 | medium=밝은 회색 / semibold=중간 / bold=진한 회색 | P1, P6 | 위계를 "면의 명도"로 정의한 것 — 대비의 정량화 |

## 2층 — 조건부 관계 규칙 ★ 제일 쓸만한 층

브로크만이 절대값이 아니라 **비례·함수 관계**로 말한 것들. "구부러지는 파라미터"의 실체.

| # | 규칙 (함수 형태) | 목적 | 원전 정당화 |
|---|------------------|------|-------------|
| R1 | `단 폭 ∝ 활자 크기` — 좁은 단 → 작은 활자. 20pt 제목엔 넓은 단, 8pt 본문엔 좁은 단 | P1 | 단이 좁은데 활자가 크면 행당 단어가 부족 → 잦은 행 전환 → 피로 |
| R2 | `행간 = f(활자 크기 집합)` — 3~4개 크기가 공존하면 각 행간을 **상호 조정** | P5 | "규칙적이고 매력적인 조판을 위해 서로 맞춰야 한다" — 행간이 독립 변수가 아니라 시스템 변수 |
| R3 | `행간 ↑ → 페이지당 행 수 ↓` (용량 트레이드오프) | P4↔P1 | 명시적 트레이드오프 서술. 목적 충돌이 규칙 안에 내장된 사례 |
| R4 | `도판 크기 = f(주제적 중요도)` | P2 | "그림의 크기는 주제에 대한 중요도에 따라 결정된다" — **의미→형태 매핑. AI 조판의 핵심 규칙** |
| R5 | `도판 크기 종류 수 ↓ → 지면의 고요함 ↑` | P5 | 책에서 유일하게 "The rule:"이라고 명명한 규칙 |
| R6 | `단 수 = f(콘텐츠 복잡도)` — 1단: 자유도 부족 / 2단: 텍스트+도판 분리 가능 / 3단: 다양하나 행폭 좁아져 작은 활자 강제 / 4단: 대량 텍스트+통계용. 세분화 2→4, 3→6, 4→8·16 | P4, P2 | 각 선택지의 장단점을 조건부로 서술. 단, "기능에 달린 문제(depends on the function)"라고 판단 위임 |
| R7 | **필드 산술**: `단 깊이(행) = n필드 × 필드당 행수 + (n−1) 공행`, 정수 해만 허용 | P5 | 57행 예제: 57−3=54, 54/4=13.5 → 반행 불가 → 13행×4+3=55행으로 재조정. **제약 충족 알고리즘이 원문에 그대로 있음** |
| R8 | 텍스트 첫 행은 필드 상단에 밀착, 마지막 행은 하단 경계선 위 | P5 | 필드-행 정합 조건 |
| R9 | 쪽번호 측면 배치 시 반드시 본문 행과 정렬. 상단 중앙 배치는 쪽번호가 특수 기능일 때만 (사전·참고서) | P5, P2 | 위치별 광학 효과를 조건별로 서술 (하단 배치=단의 기저 연장, 상단=위로 미끄러지는 인상) |
| R10 | 여백: `최소값 > 재단 공차`, 과대하면 낭비 인상, 상하좌우 비례가 균형이어야 안정 | P4, P6, P3 | "너무 좁으면 손가락이 텍스트를 가림"(인체공학 근거!), "너무 크면 빈약한 텍스트를 늘린 느낌" |
| R11 | 유사 계열 서체 혼용 금지 (Helvetica+Univers ✗, Garamond+Bodoni ✗) | P5 | 통일성 원칙의 서체 버전 |
| R12 | 누끼(cut-out) 이미지 → 밑에 단색면 깔거나 괘선 테두리로 그리드에 결속 | P5 | 비정형 요소를 그리드에 편입시키는 표준 처리 |
| R13 | 전면(bleed) 페이지는 여백 있는 페이지와 **조합**할 때 관대한 인상 | P6 | 대비를 통한 효과 — P6이 P5를 이기는 허용 사례 |
| R14 | 사진식자 기본 자간은 과밀 → 표준 자간을 명시적으로 요구할 것 | P1 | 기술 기본값 불신. 도구의 디폴트≠규범 |

## 3층 — 판단 원리 (규칙화 거부 지점)

브로크만이 **스스로 이론화 불가능을 선언한** 대목들. 예시 주석의 기준점.

| # | 원리 | 원전 발언 |
|---|------|-----------|
| J1 | **그리드는 과제마다 고유하다** | "모든 작업은 면밀히 연구되어 그 요구에 상응하는 고유한 그리드망에 도달해야 한다" — 보편 그리드 부정 |
| J2 | **판면 설계의 근본 질문들은 이론으로 답할 수 없다** | "지면을 최대로 쓸 것인가, 여백에 시각적 기능을 줄 것인가… 각 과제가 개별 해법을 요구하는 질문을 너무 많이 제기하므로 이론으로 만족스럽게 다룰 수 없다" — **명시적 이론화 한계 선언** |
| J3 | **반복 스케치·비교·소거 프로세스** | 소형 스케치 → 부적합 탈락 → 2~3개 남김 → 1:1 확대 → 재비교 → 1개. "첫 시도에 최종 해에 도달하는 일은 드물다" — 판단이 탐색 과정임을 인정 |
| J4 | **제목 위치는 전체 설계에 종속** | "제목의 위치는 해당 인쇄물의 전반적 디자인에 의존해야 한다" — 국소 규칙보다 전역 맥락 우선 |
| J5 | **규율 없으면 그리드로도 산만해진다** | 8필드 장: "디자이너가 도판 크기 사용에서 스스로를 규율하지 않으면 최종 효과는 불안정할 위험" + "구성 감각과 그림·텍스트의 리듬적 연쇄에 대한 느낌이 필요" — 그리드 준수 ≠ 좋은 결과 |
| J6 | **그리드는 도구일 뿐** | "그리드 시스템은 디자이너의 손에 쓸만한 도구를 쥐여줄 뿐, 그 이상도 이하도 아니다(no more and no less than a serviceable instrument)" — 경전 아님을 저자가 직접 명시 |

## 목적 충돌 쌍 — "판단 판례" 주석의 축

| 충돌 | 내용 | 중재 사례 |
|------|------|-----------|
| **P5 vs P6** (고요 vs 긴장) | 통일성을 요구하면서 동시에 "높은 긴장도", "대비가 풍부하고 생동하는 레이아웃"을 요구 | R13(전면+여백 조합), 8필드 장의 "대비적이고 역동적인 배열" — 긴장은 통일의 기반 위에서만 허용 |
| **P4 vs J1** (표준화 vs 개별성) | DIN 표준 판형 강권 ↔ 그리드는 과제마다 고유 | 해결: 판형은 표준, 그리드는 맞춤 — 충돌을 층위 분리로 회피 |
| **객관성 vs 개성** | 철학 장: "주관 대신 객관에의 의지" ↔ 같은 장: "모든 시각 창작은 디자이너의 성격의 발현" | 미해결 긴장으로 존속. 객관은 수단, 발현은 결과라는 독해 가능 |
| **P1 vs P4** (가독 vs 용량) | R3: 행간 늘리면 읽기 좋아지나 수용량 감소 | 콘텐츠 양이 조건 변수 |

## 프로젝트 적용 메모

1. **R4가 핵심 병목.** `도판 크기 = f(중요도)`에서 '중요도'는 콘텐츠 의미 이해를 요구 — Intent 층이 시스템에 개입하는 유일한 지점. LLM의 의미 파악 능력으로 근사 가능한지가 실험 거리.
2. **R7은 그대로 구현 가능.** 정수 제약 충족(57→55 재조정)은 constraint solver 한 개짜리 문제. 데모용으로 최적.
3. **J2·J6은 논문의 방어선.** "브로크만 자신이 이론화 한계를 선언했다"는 사실이, 시스템의 3층(판단)이 근사에 그치는 것에 대한 원전 기반 정당화가 됨.
4. **P5↔P6 충돌**이 판단 예시 재주석의 1순위 축. 《뮤지카 비바》 = P6이 P5를 이긴 판례.
5. 검증 실험: R1~R14를 켜고 끄면서 출력 비교 → 각 규칙의 기여도 ablation 가능한 구조.
