가이드 긋기 —

무엇을 하나

  1. 텍스트 블록 긋기 — 서로 붙어 있는 글줄 덩어리마다 드래그해 영역을 긋는다.
  2. 가이드 긋기 — 블록 안의 글줄마다 베이스라인 · 캡선 · 어센더선 · x높이선을 긋는다. 그을 글자가 아예 없으면 글자 없음, 글자는 있는데 위치를 못 정하겠으면 판독 불가.
  3. 완료 — 미입력과 잘못된 상태가 0 이 되면 완료하고 다음 포스터로. 하루가 끝나면 내보내기.

화면 오른쪽 위 «지금 할 일» 이 늘 다음 동작을 알려준다. 자세한 규칙은 요청서(docs/LABELING_REQUEST.md). 이 도구에는 검출 결과나 프로그램 출력이 들어 있지 않다.

크롬(Chrome)으로 연다. 다른 브라우저에서는 자동 저장이 안 될 수 있으니 중간중간 내보내기 한다.
