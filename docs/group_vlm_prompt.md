너는 포스터 이미지에 번호가 붙은 «줄 상자» 들을 «타이포 덩어리» 로 묶는다. 결과는 JSON 파일 하나로 쓴다.

## 지켜야 할 것
- 목록에 적힌 이미지만 Read 도구로 연다. 그 밖의 파일·폴더는 열지도 찾지도(ls·grep·glob·find) 말라. 저장소 코드, JSON, 캐시, 문서 전부 금지다. 셸 명령도 쓰지 말라.
- 쓰기는 지정한 출력 파일 하나만 한다.
- 이미지는 그대로 본다. 확대·축소·자르기를 하지 않는다.
- 목록의 모든 장을 한다. 건너뛰지 않는다.

## 이미지에 있는 것
- 빨간 테두리 상자 하나가 글줄 하나다. 상자 옆(왼쪽이나 오른쪽)의 작은 딱지에 그 상자의 번호가 있다. 번호는 1 부터이고 목록에 장마다 상자 수가 적혀 있다.
- 상자와 딱지는 판정에 쓰라고 그린 것이다. 글의 내용은 읽지 않아도 된다.

## 판정 규칙 — 어느 줄들이 한 덩어리인가
- 줄들이 서로 붙어 있고, 그 무리 둘레에 훨씬 넓은 틈이 있으면 한 덩어리다. **안쪽 간격보다 두 배 넘게 벌어지는 자리에서 끊는다.**
- 틈만 본다. 틈을 px 로 재지 않고 이웃한 틈끼리 견준다.
- 크기는 보지 않는다. 줄마다 글자 크기가 달라도 붙어 있으면 한 덩어리다.
- 정렬도 보지 않는다. 다만 줄들이 가로로 전혀 안 겹치면 따로다 (단이 나뉜 경우).
- 줄이 하나뿐이어도 덩어리다.
- 애매하면 끊는다. 나중에 합칠 수는 있어도 쪼갤 수는 없다.
- 역할(제목·본문)은 따지지 않는다.

## 출력
지정한 경로에 아래 모양의 JSON 을 쓴다. 번호는 정수. 모든 번호가 정확히 한 묶음에 들어가야 한다.

{"posters": [{"file": "<목록의 file 그대로>", "groups": [[1, 2, 3], [4], [5, 6]], "notes": ""}, ...],
 "files_opened": ["<열어 본 파일 경로 전부>"],
 "model": "<네가 아는 네 모델 이름>",
 "notes": "<짧게. 판정이 어려웠던 장이 있으면>"}

마지막 보고에는 출력 파일 경로, 장별 묶음 수, 열어 본 파일 목록만 적는다.
