# 뇌를 쓰는 법

새 세션에서 이 파일부터 읽으면 된다. MCP 서버 `typo` 가 이미 등록돼 있고
(`~/.claude.json`), 도구 11개가 붙는다.

---

## 뇌가 무엇인가

한 작가의 스타일을 **그래프**로 담은 것이다. 값 목록이 아니다.

    마디   측정된 속성 21개와 그 값·흔들림·판정·커버리지·주의사항
    선     그 작가 «안에서» 직접 이어진 속성 쌍 (편상관)
    cannot_say   이 뇌가 «말할 수 없는 것»

왜 목록이 아니라 그래프인가. 코퍼스 4종 274장을 재보니 **값으로는 작가가
거의 안 갈렸다.** 몰린 값은 넷이 다 공유했고(어센더/x높이 1.35~1.40 은
악치덴츠의 성질이지 작가의 선택이 아니다) 갈리는 값은 흩어져 있었다.
갈리는 것은 «묶임» 이었다.

그리고 생성이 전에 실패한 이유도 이것이었다. 값을 지표마다 따로 뽑으면
각 값은 브로크만 범위 안인데 합쳐 놓으면 브로크만이 아니다.

## 도구

| 도구 | 하는 일 |
|---|---|
| `list_brains` | 어떤 뇌가 있나 |
| `style_brain` | 뇌 하나. 혼자 선다 — 다른 작가가 필요 없다 |
| `compare_brains` | 뇌 둘 이상을 겹쳐 본다. 비교는 여기서만 |
| `pool_brains` | 코퍼스 여럿을 합쳐 새 뇌 |
| `add_designer` | 포스터 폴더 하나로 작가를 늘린다 |
| `measure_boxes` | 포스터를 보고 상자를 짚어 주면 그 안을 잰다 |
| `measure_corpus` | 폴더를 자동 검출로 잰다 (비교 대상) |
| `show_rules` · `style_card` | 값 목록 쪽 |
| `place_text` · `check_layout` | 배치 계산과 검사 |

첫 손짓은 보통 이렇다.

```
list_brains  →  style_brain {"cache": "~/.typo-mcp/brockmann.json"}
```

## 읽을 때 지켜야 할 것

**cannot_say 를 먼저 읽어라.** 하루에만 귀무모형 없이 숫자를 보고 판단을
여섯 번 뒤집었다. 특히 —

- **선은 «함께 움직인다» 까지다.** 어느 쪽이 먼저인지는 상관으로 알 수 없다.
  「마진을 먼저 정하고 내용을 담는다」 같은 말은 데이터가 뒷받침하지 않는다.
- **연작이 판형을 고정하면 그것이 «그의 방법» 처럼 보인다.** 계열마다 한 장씩
  뽑아 다시 재면 결합도가 달라진다 (0.21 → 0.35).
- **마진과 덮음은 같은 검출 상자에서 계산된다.** 둘 사이 관계에는 설계가
  아니라 셈법에서 오는 몫이 섞여 있다.
- **행간비는 브로크만 123장 중 86장에서만 나온다.** 값이 나온 포스터는 무작위
  표본이 아니다 — 검출이 쉬운 얌전한 조판에 쏠린다.

**verdict 와 scope 는 다른 질문이다.** 앞은 「이 코퍼스에서 값이 몰렸나」,
뒤는 「그 값이 다른 작가와 갈리나」. 자주 엇갈린다.

## 생성에 쓸 때

    sample.draw(raw, brain['edges'], joint=True)

뇌의 선만 남긴 정밀도 행렬을 뒤집어 코퓰러로 뽑는다. 그러면 실제 상관과
평균 0.08 차이가 난다 (지표마다 따로 뽑으면 0.45).

`render.py` 가 그 값으로 판면을 그린다. **아직 절반만 된다** — 자리(무게중심·
흩어짐)는 3~6% 안에 들어오는데 밀도(덮음)와 활자 낙차(활자폭)가 76~81%
어긋난다. 검출기가 큰 활자를 블록으로 못 잡는 것이 원인 중 하나다.

## 오늘 확인된 것 몇 가지

- **무게중심이 마진보다 고정이다.** 브로크만의 글자 무게중심은 판면 가로
  47%·세로 53% 에 앉고 CV 0.22 다. 마진은 CV 1.0~1.4 로 제멋대로다.
- **책이 말한 규칙 중 R2 는 지킨다.** 한 판의 행간들은 하나의 단위의 정수배다
  (벗어남 2.4%, 귀무 7.3%). R1·C1 은 어긋나는데 그것은 «책» 규칙이라 포스터에
  대고 잰 것이 범주 오류다. `booktest.py` 참조.
- **책에 없는 관계가 8개 있다.** 그중 허브는 마진좌 — 위·아래 마진과 같이
  움직이고 행간과는 반대로 간다. 책 어디에도 없다.

## 뷰어

```bash
python viewer/build.py        # ~/.typo-mcp 의 뇌로 한 파일 HTML 을 굽는다
```

작가를 여러 개 고르면 판을 갈라 나란히 놓는다. 마디 자리가 판마다 같고,
고른 뇌 모두에 있는 선은 회색으로 물러나며 한쪽에만 있는 선이 색을 얻는다.
